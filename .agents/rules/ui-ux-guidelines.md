# UI/UX & Design Guidelines for Candidate Dashboard

Every user interface component and visual workflow must follow these quality standards:

1. **Aesthetic Excellence**: Use modern dark/light themes, sleek gradients, glassmorphism (`backdrop-blur-md`), and 1px border subtleties.
2. **Productivity & Ergonomics**:
   - Provide multi-view navigation (Table, Kanban, Analytics, Urgent Queue).
   - Fast filter chips & instant search.
   - Bulk selection and export capabilities.
   - Drawer / Quick-peek modal with keyboard / Next-Prev navigation.
3. **Clarity of Status**: Color-code CV & Interview outcomes unmistakably (Emerald = Pass, Rose = Fail, Amber = Pending, Cyan = Interview, Purple = Onboarded).
4. **Responsive & Mobile Ready**: Clean collapsible layouts, touch-friendly tap targets, readable font sizes on mobile and desktop.
